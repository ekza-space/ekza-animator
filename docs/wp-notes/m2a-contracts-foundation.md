## Interpretations and decisions

| # | What | Why |
|---|---|---|
| M2A-A0-1 | **Menu-bar Time items without `at`.** Time › Insert Frame `{frames: 1}`, Remove Frame `{frames: -1}` and Delete Time `{frames: -1, removeKeys: true}` pass no `at`; **A3 resolves `at` from the current frame (Delete Time: the band)** when it is absent. | Menu items carry static arguments, so a menu-bar item cannot name the current frame. The time-slider context menu (A3) passes `at` explicitly. Alternative: a contract PR making `at` optional in `OperatorMap`. |
| M2A-A0-2 | **Rig › IK/FK is one sub-menu with a group per limb** (Switch to IK/FK, Match FK to IK, Match IK to FK, Match Range to FK/IK for L Leg, R Leg, L Arm, R Arm); Rig › Add Limb IK is a top-level item. The shell labels the sub-menu `IK/FK` (`SUBMENU_LABELS` in `shell/menus.ts`). | Every IK/FK operator requires `limb` (§4.5), and menu arguments are static. |
| M2A-A0-3 | **Stubs that A0 implements anyway:** none. `key.setTarget` and `key.toggleRipple` are stubs like the rest (§3 rule 1), so the status-line key-target items are disabled (tooltip "not available yet") until A2 registers `key.setTarget`; the active item stays enabled. | The toggle polls the operator per item, so it enables itself when A2 lands. |
| M2A-A0-4 | `key.set` (A2's file) poll-fails `target: 'bodyPart'` ("Keying by body part is not available yet") and `breakdown: true` ("Breakdown keys are not available yet") instead of keying the M1 way; `channels: 'attributes'` is accepted by the type and keys no TRS channel. | A silent normal key on `Alt+S` would look like a breakdown that never retimes. The `keyTargetControls` baseline is ready for A2. |
| M2A-A0-5 | **Probe map keys:** `dopeSheet` (A3) and `tween.graph` / `tween.dopeSheet` / `tween.status` (A4, `tweenProbeKey(panel)`); A4's `graph().viewMode` and `screenOfRegionHandle` and A3's `timelineTicks` and `screenOfBand` are **optional members** of the existing graph and timeline probes (the test API answers `'absolute'`, `null` or `[]` without them), so the M1 probes compile unchanged. `graph().buffers` comes from `session.curveBuffers`, not from a probe. | "keyed by the bar's panel" with the registry's one-probe-per-key semantics; additive for the M1 probe owners. |
| M2A-A0-6 | **Test API reads flush the scheduler first** (`app.flushScheduled()` in `state`, `curves`, `channelValues`, `overrides`, `boneWorld`, `attrs`, `controlWorld`, `curveSlope`, `limbs`, `limbPivots` and every probe-backed read: panes, cameras, screen positions, panel states). Frame loops call it first: the GL host and fallback scheduler (`frameLoop.ts`) and the dev harness's standalone viewport host. `curveSlope` is exact: at a key the left side is the end slope of the span before it and the right side the start slope of the span after it (from `segmentControlPoints`); outside the range the infinity decides. `flushAutosave()` rejects while `file.autosaveNow` poll-fails (A5). | Coalesced gesture updates (M-1) must not make a probe read stale state between a pointer move and its frame. |
| M2A-A0-7 | **`scheduleBeforeFrame` details:** a later task with the same key replaces the pending one and keeps its place in the order; tasks scheduled during a flush run in the same flush (bounded at 10,000); a throwing task does not stop the others, the first error is rethrown after the flush. "Without a frame requester" means before the host calls `setFrameRequester` (Node, the test kit). `KeyEditGesture.commit` drops a pending update; `beginChannelEditGesture.commit` applies its pending update first (its `commit()` takes no final edit). | One rule for the frame loop, pointerup and tests. |
| M2A-A0-8 | **Attribute slots repair, never reject:** a non-object `AttrDef` gets no slot; a non-finite default reads 0. `writeAttr` ignores unknown attributes and non-finite values; `readAttr` answers `undefined` for unknown controls or attributes. Overrides and `writeControlChannels` write `'@name'` channels. | MVP-SPEC §3 rule 6 (repair, never reject). |
| M2A-A0-9 | **A `compile` that throws** marks the scheduled op `skipped` (`ScheduledRigOp.skipped`) and warns `unsupported-op`; the op stays scheduled. The kernel reuses one run context object per program (no allocation per frame). | §4.3 "a throw disables the op for this program (it is skipped at run time and warns)". |
| M2A-A0-10 | `sampler/cache.ts` (A4's file after A0) got the minimal attribute-sampling change (a plan entry's `attr` slot and its `AttrDef` default); `insertKeyOnCurve` uses `channelDefaultOf` for key-less attribute curves. | §5.1 rule 3 sampling is A0's; the sampler lives in that file. A4 rebases on it. |
| M2A-A0-11 | **`ensureCurve` is the shared curve-creation helper** of §5.23: on a loop clip every curve it creates (keys, static values, rotate-order conversion) gets `cycle` infinities; existing curves are never rewritten. Imports keep `constant` (they create curves through `workflows/records.ts`). | One place for "new curves on loop clips". |
| M2A-A0-12 | **Storage switches:** `ns=<1–64 of [A-Za-z0-9_-]>` makes the e2e editor use localStorage under the prefix `ekza-animator:ns:<ns>:` (preferences and layout persist across a reload of the same URL); `storage=blocked` gives a storage whose every access throws a `SecurityError` (every consumer already guards it). `createBrowserServices`/`createShellServices` take `storageNamespace`, `storageBlocked` and `pointerLock` (exported as `BrowserServicesOptions`); A5 uses the first two for the autosave database, A2 reads `pointerLock` from `shell.params.pointerLock`. | §4.8 URL parameters. |
| M2A-A0-13 | **Layout v1 → v2** runs on the dockview API, not on the serialized JSON: the v1 layout is restored, `addDopeSheetTab` adds the tab to the Graph Editor's group (or a new bottom group), and the result is written under the v2 key; the v1 key is only read. `readStoredLayout` returns `{kind: 'migrate', from: 1}` for it. Without a v2 layout and with an invalid v1 layout the M1 reset notice shows. | The grid tree of a serialized dockview is not something to edit by hand. |
| M2A-A0-14 | **Prefs:** the M2a fields load field by field (nested objects too); `prefs.set` accepts them, and `ikFkVisibility: 'ghost'` poll-fails "not available yet" (M2a-stretch). `ui.open {dialog: 'recovery'}` poll-fails "not available yet" until A5 mounts the Recovery dialog (File › Recover… is in the menu). | §1.2 fallbacks, §7 menus. |
| M2A-A0-15 | **Not done by A0 (owners named):** the oxlint `no-restricted-imports` rule that keeps `editor-core`/`editor` off the main-entry export names (A5, with the dynamic `import('@ekza-animator/io/write')` that it requires); the CI workflow step for `check:size` (A5, with the gate); `READY` flag files (`test/ready.ts`, each package that needs one); the §5.4 rule 2 edge change and `RigProgram.limbs` construction (A1); `applyChannelEdits` for attributes and the unit-aware callers (A2). | §8 ownership. |
| M2A-A0-16 | **`--rig-pole-line`** is `rgba(200, 204, 212, 0.6)` (the light foreground at 60 % alpha), added to `packages/ui/tokens.json` and generated into `css/tokens.css` (`node packages/ui/scripts/build-tokens.mjs`). | `tokens.css` is generated; its test checks the source. |
| M2A-A0-17 | The FR-GE-17 entry of `apps/web/e2e/stretch.spec.ts` is a passing test (§5.23): C¹ at the seam on the wave clip with cyclic infinities, and with a key that gives the seam velocity (non-zero slope). | §5.23 "the stretch.spec.ts FR-GE-17 entry becomes a passing test". |
